How to set up Gmail for ShieldScan

ShieldScan uses Gmail SMTP to send alerts. Follow these steps to configure it:

1
Go to your Google Account → Security → 2-Step Verification and make sure it is turned ON
2
Go to Google Account → Security → App Passwords
3
Select app: Mail — Select device: Windows Computer — Click Generate
4
Copy the 16-character app password Google gives you
5
Open app.py and replace your_gmail@gmail.com and your_app_password with your actual Gmail and the app password
6
Restart the server and click Send Test Email above to confirm it is working
What the alert email contains:
- Exact detection timestamp
- Location where no mask was detected
- Confidence percentage of the detection
- Name of the operator who was logged in
- Professional HTML formatted email layout
